# Azure Security Lab
 
Hands-on Azure cloud security labs covering secure infrastructure design, log
collection, and detection engineering.
 
## Labs
 
| # | Lab | Description |
| --- | --- | --- |
| 01 | [Secure VM and Log Collection](01-secure-vm-and-log-collection) | Deployed a hardened Linux VM with no public IP and Bastion access, shipped auth logs to Log Analytics through the Azure Monitor Agent, solved an agent egress failure with a NAT gateway, and wrote KQL to detect privilege escalation, failed logins, and account creation. |
